# 运行手册

## 一、分桶清单

地区和领域各铺一遍，再按缺口补。每桶 4 个查询，**单批 ≤ 8 个查询**。

**地区桶**（优先平时刷不到的）

- 中东：伊朗、以色列、也门—沙特、叙黎
- 欧洲：俄乌、欧盟、英法德、南欧（意西）
- 东亚：日本、韩朝、中国政策、台海
- 东南亚 / 南亚：印度、巴基斯坦、印尼越南泰国、孟加拉—斯里兰卡
- 非洲：苏丹、尼日利亚、南非、埃塞—肯尼亚
- 拉美：巴西、阿根廷、墨西哥、智利—哥伦比亚
- 北美 / 大洋洲：美国政治、加拿大、澳大利亚新西兰、太平洋岛国

**领域桶**

- 经济金融：美联储/央行、股市、油价能源、贸易关税
- 科技：AI、芯片、航天、量子
- 医药 / 气候：新药、世卫、COP、极端天气
- 文化：时尚、影视、音乐、艺术、游戏、体育

查询词加**城市名或机构名**（「釜山 地铁 工会」）比泛词（「非洲 新闻」）干净得多。

## 二、候选池

把每轮结果落成一个 JSON：

```js
{ id, bucket, title, url, snippet, date }
```

按 url 去重后再选。候选池放 `工作区/YYYY-MM-DD-候选池/`，7 天一清。

## 三、选区经验

- 先按「今天发生了什么」定 3–5 个必收事件，再用冷门地区补配额；
- 机构源（联合国、世卫、WMO、非盟疾控、国家统计局）常能补非洲 / 太平洋 / 人道议题；
- 文化类优先「当天发生」（颁奖、开播、开展、开唱），少收一周前的预告；
- 同一展会 / 同一会议最多 3 条，拆成不同角度（人事、商业、技术）。

## 四、抓原文

```js
function toText(html) {
  const title = (html.match(/<title[^>]*>([\s\S]*?)<\/title>/i) || [])[1] || "";
  let s = html.replace(/<script[\s\S]*?<\/script>/gi, " ")
              .replace(/<style[\s\S]*?<\/style>/gi, " ")
              .replace(/<[^>]+>/g, "\n")
              .replace(/&nbsp;/g, " ").replace(/&amp;/g, "&");
  const lines = s.split("\n").map(x => x.trim()).filter(x => x.length > 25);
  const body = lines.filter(x => /[。！？]/.test(x) && x.length > 40).slice(0, 5).join(" ");
  const d = html.match(/(20\d{2})[-年\/](\d{1,2})[-月\/](\d{1,2})/);
  const date = d ? `${d[1]}-${String(d[2]).padStart(2,"0")}-${String(d[3]).padStart(2,"0")}` : "";
  return { title, date, body: body.slice(0, 560) };
}
```

- 失败一次就回退标题，**不重试**；
- 有些站会跨域重定向，按报错给的地址重试一次即可；
- 抓取上限控制在 20–30 篇，够核对事实和日期就行。

## 五、落盘与命名

```text
输出/YYYY-MM-DD-新闻日报/
├─ 新闻日报.md
└─ 交付说明.md
```

通过验收后整体移到 `输出/已归档/`，目录结构不动，旧版本不删。

## 六、底账四件套

| 文件 | 记什么 |
| --- | --- |
| 已发索引 | 一行一条：日期 / 标题 / 一句话 / 地区 / 领域 / 来源 |
| 成本台账 | 检索次数、候选数、采用数、估算 token |
| 来源分级 | 本期用到的新域名 + 可抓性判定 |
| 日记 | 本期口径、踩的坑、下次怎么绕 |
