# 验收自检

交付前逐项打勾，任何一项不过就不交。

## 结构与数量

- [ ] 条数 45–55
- [ ] 三节齐全且在配额内（10–14 / 16–22 / 10–20）
- [ ] 文化 / 时尚 / 娱乐占比 20%–40%
- [ ] 不同国家 / 地区 ≥ 15
- [ ] 领域 ≥ 15 类

## 质量

- [ ] 同一事件只出现一次；主题簇 ≤ 10%
- [ ] 每条「标题 + 一句话」，无背景长文
- [ ] 每条能回答「我知道了一件什么事」，不是「一个数」
- [ ] 纯榜单 / 纯数字未单独成条
- [ ] 八卦标了「已证实 / 传闻 / 已辟谣 / 争议」
- [ ] 标题不以国名开头，≤ 30 字
- [ ] 每条来源是文章页，不是首页凑数

## 时效与记忆

- [ ] 开头标了截止日期 / 条数 / 文化占比
- [ ] 无超过 3 天且无新进展的旧闻
- [ ] 已发索引已追加本期条目
- [ ] 与近 30 天索引无重复（标题相似度抽查 < 0.3）
- [ ] 成本台账已记一行

## 交付

- [ ] 日报 + 交付说明同目录
- [ ] 交付说明写了「已知局限」和 2–3 个具体反馈问题
- [ ] 待审 → 验收后移入 `输出/已归档/`，目录结构不变

## 机器可跑的最后一遍

```js
// 结构校验
const items = [...md.matchAll(/^\*\*(\d+)\. (.+?)\*\*\n(.+?)\n(.+)$/gm)];
items.length;                       // 45–55
items.filter(i => i[2].length > 30);  // 应为空
items.filter(i => /^(中国|美国|俄罗斯)/.test(i[2])); // 应为空
```
