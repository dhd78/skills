# 来源分级

| 级别 | 含义 | 处理 |
| --- | --- | --- |
| A | `web_fetch` 能取到正文 | 重要条目抓全文再写摘要 |
| B | 只能取到片段或 404 | 用片段或标题写一句话，保留链接 |
| C | 本机直连不可用 | 只从 `web_search` 结果里取 |

## 实测（2026-10 至 11 月）

**可抓正文（A / 准 A）**

`news.cn`、`xinhuanet.com`、`people.com.cn`、`gov.cn`、`cctv.com` 与 `cctv.cn`、`un.org`、`163.com`（多数）、`shopex.cn`、`ithome.com`、`rednet.cn`、`sohu.com`（部分）

**抓不到或返回空正文（B）**

`mitrade.com`、`cast.cn`、`reliefweb.int`、`allafrica.com`、`archiproducts.com`、`adhadhu.com`、`agenciabrasil.ebc.com.br`、`toutiao.com`（部分）、`weibo.com`

**结构性不可用（C）**

BBC、Reuters、Guardian、Al Jazeera 等常 404（上游抓取挡）；本机 DNS 若被污染，curl 与 RSS 一律不可靠——不要绕，只用 `web_search` 给出的链接。

## 规矩

- 不关 TLS 校验、不装陌生根证书、不绕付费墙；
- 同一稿多域名转载，只留原发；
- 每期把新域名的判定补进本表。
